# Gravity Circle

An interactive gravity-based circle built with HTML, CSS and vanilla JavaScript.

Scroll to rotate the circle.
Stop scrolling and gravity takes over.

## Live Demo

👉 **[Open Live Demo](https://p1noky0.github.io/gravity-circle/)**

## Features

- Scroll-controlled rotation
- Gravity-based return motion
- Inertia
- Damping
- Smooth swinging motion
- Responsive design
- No frameworks
- No dependencies

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
